I Suck at Fantasy

A full-stack NFL data platform built from scratch

🛠️

Tech Stack

  • Node.jsPlain HTTP server — no Express, no framework
  • SQLitebetter-sqlite3 for fast synchronous queries; WAL mode
  • Vanilla JSZero front-end frameworks; all UI written by hand
  • Tank01 APIRapidAPI — live game data, scores, player logs
  • Sleeper APIFree tier — full 2026 player roster, free and unlimited
  • RenderDeployed on Render's free tier (Node web service)
  • GitHubSQLite DB hosted in-repo (4.4 MB, no LFS needed)
📐

Architecture

API Tank01 / Sleeper fetch player & game data
↓
DB SQLite stores players, game logs, season stats, schedules, team records
↓
API Node.js serves JSON endpoints: /api/standings, /api/player-stats, /api/games, /api/power-rankings, etc.
↓
UI Vanilla JS renders tables, charts, and live game cards
✨

Features

  • Live game scores with real-time ball marker and play-by-play
  • NFL standings with playoff seeding algorithm and SOS calculations
  • Player leaderboards for QBs, RBs, WRs, TEs, and defenders
  • Power rankings using a weighted record + scoring formula
  • Player comparison tool with week-by-week sparkline charts
  • Game recap pages with full player boxscores
  • NFL Wordle — daily guess-the-player game
  • Fantasy roster integration (Sleeper)
  • Light & dark mode, keyboard calendar navigation
🗄️

Database

  • players~4,000 NFL players with ESPN IDs, positions, draft info
  • game_logsPer-player per-game stats for 2025 and 2026 seasons
  • team_game_logsPer-team box scores after every live poll
  • schedulesFull 2026 schedule with home/away and final scores
  • season_player_totalsAggregated season stats, rebuilt after each game week
  • team_season_statsWins, losses, PPG, PAPG for all 32 teams
